# Article media

Public media for the Festival Notebook tutorial. The cover and workflow diagram were AI-generated. The screenshots show actual app runs; the Android illustration and speech WAV are recorded model outputs.

- `macos-answer.png`: current native app, real text-model answer.
- `web-answer.png`: GitHub Pages deployment in Chrome, real text-model answer; speech disabled for this check.
- `android-answer.png`: earlier Android emulator UI and answer.
- `android-illustration.png`: earlier SDXS fixed rain-plan prompt, not the current conversation-derived prompt.
- `mo-android.wav`: Qwen3-TTS synthesis on Android; 3.52 seconds at 24 kHz mono. Input: “The Berry Festival moves into the village hall when it rains.”

These files contain no model weights. See the repository's asset credits and MIT license. Detailed experimental speech findings are linked from `docs/platforms.md`; the old development archive is not the runnable public example.
